# VideoArchive

把游戏录像整理成一个能搜、能看的档案库（界面里叫「录像档案」）。

它把**封面、时长、分辨率、录制时间**读出来摆成卡片墙；标题、游戏、摘要、标签由你自己填。**不移动、不改名你的视频文件**，怎么整理都在它自己的数据库里。

**纯本地，不调用任何模型，视频一个字节都不上传。**

---

## 一眼看懂

- **零外部服务**：只用到本机的 ffmpeg（读视频信息、抽封面），没有账号、没有 API key
- **不后台打扰**：只有「打开页面」和「点 ↻」两个时刻会扫一遍你设定的文件夹；不监听、不定时轮询、不写你的视频
- **游戏库**：游戏名 + 别名 + 类别，卡片可按游戏/类别筛
- **档案是本地 JSON**：默认在 `~/.dsh/VideoArchive`，可以改到录像目录里，跟着硬盘一起走

## 安装

```powershell
git clone https://github.com/lianglllll/VideoArchive.git
cd VideoArchive
.\install.cmd
```

装到哪个目录都行，不用固定位置。`install.cmd` 会自己找 Node（PATH 里没有就用 DSH 自带的那份），然后把它挂进 DSH。

> 没有 Node 的话先 `winget install OpenJS.NodeJS.LTS`。也可以手动跑 `node install.mjs`，效果一样。

然后重启 DSH。左侧导航会多一项 **录像档案**；也可以直接访问
`http://127.0.0.1:<DSH 的端口>/video-archive/`

### 从别的电脑拷

把整个插件文件夹拷过去，进去双击 `install.cmd`（或者 `node install.mjs`）。

> 卸载：`.\install.cmd --remove`，再重启 DSH。插件文件和数据都会留着。

> **更新插件后必须完全退出 DSH 再启动**（包括托盘里的进程），只刷新页面不够：页面是新代码，后端还是旧代码，会看到「插件已更新，请重启 DSH」的提示。

### 需要什么

| 依赖 | 说明 |
| --- | --- |
| DSH | 插件宿主，装好就能用 |
| ffmpeg | 读视频信息、抽封面。**没装也能用**：视频照样能加进来、填描述、搜索，只是没有时长和封面 |
| 可选 | 已经装过 ffmpeg 的（winget / scoop / 剪映自带）不用再装，插件会自己找到 |

插件的查找顺序（找到就用）：

```
① 环境变量 VA_FFMPEG / FFMPEG / FFMPEG_PATH
② <插件目录>/bin/
③ ~/.dsh/tools/ffmpeg/bin
④ scoop、winget 装的位置、PATH、C:\ffmpeg\bin 等常见目录
```

### 缺东西的时候：依赖体检

设置 → **环境**，或者直接让 agent 跑 `video_archive_deps`，会逐项体检并给出**可直接执行的修法**：

```
✓ ffmpeg           ffmpeg version N-128532 ...  路径：C:\Users\xxx\.dsh\tools\ffmpeg\bin
✓ 档案目录可写      D:\GameVideo\.VideoArchive
✓ 录像文件夹        D:\GameVideo
✓ Node.js          v24.21.0
```

缺 ffmpeg 时那一条会直接写：

```
找不到 ffmpeg（读时长、抽封面要用它）。任选一种解决：
① 装一个：winget install Gyan.FFmpeg
② 用环境变量指定：set VA_FFMPEG=D:\path\to\ffmpeg.exe
③ 把 ffmpeg.exe 和 ffprobe.exe 放进 <插件目录>\bin 或 ~/.dsh/tools/ffmpeg/bin
```

**不打包第三方二进制、也不自动下载**——这样仓库干净、不牵扯再分发许可；装上之后回设置页点「重新检测」，已经加进来的视频点详情里的 ⟳ 补信息。

## 四个页签

- **待处理录像**：只放还没填过信息的「收件箱」；填过标题/游戏/摘要就会从这里消失，只剩在「游戏录像」里
- **游戏录像**：像资源管理器一样按 `游戏 → 年 → 月 → 日` 点进去。游戏层是带封面的卡片，年/月/日层是一行一条的列表，最后是那天的视频卡片（面包屑可以随时往回点）。右上角有搜索框，能搜标题 / 游戏 / 标签 / 摘要 / 文件名，搜到就直接平铺结果
- **游戏库**：管游戏名、别名、类别
- **设置**：录像文件夹、抽帧数

## 收录像

设置 →「录像文件夹」点「选择文件夹…」选一个（弹系统原生的文件夹选择框），需要的话勾上「包括子文件夹」。

之后每次打开录像档案页面，它都会扫一遍那个文件夹，把**还没进档案**的视频收进来（已经在的跳过，`.VideoArchive` 自己也会跳过）。正在录的文件会标「录制中」，录完自动补时长和封面。

- 页面右上角的 **↻** 按钮可以立刻再扫一次
- 第一次收进来的大文件，后台要读 6 帧关键帧：USB 机械盘上的 8GB 文件大约 2–3 秒/条，卡片先显示「入库中」，跑完自动补上封面和时长（不用手动刷新）
- 不常驻后台、不监听文件系统、不定时轮询——只有「打开页面」和「点 ↻」这两个时刻会读目录

## 日常怎么用

1. 打开页面会自动收新录像（见上一节）
2. 新加的视频出现在「待处理录像」；填完保存后它就从这里消失，去「游戏录像」里按游戏和日期找
3. 点开某一条：
   - 左边能直接播放，下面 6 张关键帧点一下就跳过去
   - 右边填**标题、游戏、摘要、标签**——游戏从下拉框里选（想新建游戏去「游戏库」页签）
   - 点 **保存修改**
   - 详情右下角的 **📂** 打开所在文件夹，浏览器放不了的格式（部分 mkv/flv）用系统播放器看
   - 最右边的垃圾桶：**只从档案移除**（文件留着）或**连文件一起删**（进回收站，能找回）
6. 设置里可以 **导出 Markdown / JSON**，贴到剪辑工程或视频简介里

## 游戏库

顶部 **游戏库** 页签里，所有出现过的游戏会聚成一条一条：

- **搜**：按游戏名或别名搜
- **类别**：每个游戏可以挂一个类别（动作 / 射击 / 角色扮演…），上面一排类别筛选，卡片上显示视频数
- **别名**：给一个游戏填多个别名（例如 `ELDEN RING`、`老头环`），手册里叫法不统一也不会散成好几条
- **合并**：两条重复的游戏，点开其中一条 →「合并到」→ 选目标，下属视频会一起改过去
- **封面**：点开游戏 →「上传图片」传一张（PNG / JPG / WebP，最多 8MB）；「用默认」回到第一条有封面的视频
- **新建**：还没录像时也可以先把游戏和类别建好
- **管理类别**：类别可以加、改名、删除（删掉后游戏回到「未分类」）

## 边录边记（文件还在写的时候）

OBS 正在往文件里写的时候也可以先加进来：

1. 正在写的文件加进来时会标「录制中」，照样能先写描述
2. 加进来那张卡会显示 **「录制中」**，没有封面和时长——但**描述可以立刻填、立刻保存**
3. 录完（OBS 释放文件）之后，插件自己每 30 秒重试一次，读出来就自动补上时长、封面和关键帧，卡片变成正常样式

为什么能这样：读不出信息时，插件会看文件是不是「最近还在变」。是的话就当成录制中，先让你写，不报错；不是的话才记成真错误。

> 注意：这个重试只针对**已经在档案里、状态是「录制中」**的文件，不会去翻文件夹。

## 单独开一个窗口（边聊边看）

在 DSH 侧栏打开时，右上角会多一个 **↗ 图标按钮**：点一下弹成单独的浏览器窗口，你就能一边和 agent 聊天、一边翻录像。

- 那个窗口打开的是真实地址 `http://127.0.0.1:<DSH端口>/video-archive/`（不是 `dsh-app://`），功能完全一样
- 浏览器如果拦了弹窗，会提示你这个地址，复制到浏览器打开即可
- 注意：DSH 重启后端口会变，那个旧窗口就失效了，回侧栏点一次 ↗ 再开一个

## 数据与结构

档案就放在**你的录像文件夹里**：`<录像文件夹>\.VideoArchive`，跟着视频一起走。没设录像文件夹时，才用 `~/.dsh/VideoArchive`。

```
<录像文件夹>\.VideoArchive\
├── config.json        抽帧数等设置
├── index.json         所有视频的记录（时长/封面/你填的标题游戏摘要标签）
├── games.json         游戏库（游戏名 / 别名 / 类别）
├── thumbs/<id>/       每条的封面、6 张关键帧、联系表
└── covers/            你给游戏上传的封面图
```

- **一个文件夹 = 一个档案库**：换成别的文件夹时，插件在新文件夹里建一套**空的** `.VideoArchive`（只带设置，不搬记录）；原来那个文件夹的档案原样留着，切回去还能接着用
- 把硬盘拿到另一台机器：档案和视频在一起，指到同一个录像文件夹就接着用
- 视频文件本身不在这个目录里，插件只写记录和缩略图

```
video-archive/
├── index.js          插件入口：注册 HTTP 页面和工具
├── client.js         侧栏入口 + 设置页里的「录像档案」卡片
├── install.mjs       挂进 DSH profile 的安装/卸载脚本
├── lib/
│   ├── archive.js    收录、队列、抽帧、保存的主流程
│   ├── ffmpeg.js     找 ffmpeg / 执行命令
│   ├── deps.js       依赖体检（ffmpeg / 目录 / Node）
│   ├── frames.js     抽帧 + 拼联系表

```

## 常见问题

**刚录完的视频还显示「录制中」/ 时长是 0**
文件被 OBS 占着的时候读不出时长。插件每 30 秒自动重试一次，录完就会补上；想立刻补就点详情里的 ⟳。

**列表里没出现新录的视频**
扫描只在「打开页面」和「点 ↻」时发生。页面一直开着的话，点一下 ↻。

**浏览器打不开视频**
mkv / flv / avi 这类格式浏览器支持不好，点详情里的 📂 打开文件夹，用系统播放器看。

**换机器后显示「文件不在了」**
说明这条的文件已经不在它记录的路径上了——文件夹改名、移动或文件被删了。卡片上会标「文件不在了」；不想要了就删掉这条记录，想接着用就在设置里把「录像文件夹」指回去。
